


# TRUNG TÂM TIẾNG ANH
## Giới Thiệu
- **là một trông số các trung tâm TA ut trong cả nước**
- *Cam kết đầu ra chuẩn theo yêu cầu*
## Cách Đăng Ký 
| Thu mục| Nội dung|
| --- | --- | 
| logs | dòng mã điều khiển |
| Data | Lưu trữ dữ liệu |
| media | lưu trữ ảnh |
Các bước đăng kí học tại TTA :
1. Liện hệ với TTA
2. Lựa chọn khoá học phù hợp
3. Đóng tiền khoá học đã chọn

```powershell
Get-Content Noi-dung | Select-String Noi-dung >> Noi-dung
```
